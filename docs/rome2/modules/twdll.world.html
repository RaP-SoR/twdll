Functions

Capture (world)
Captures the WORLD singleton from a vanilla world script-interface userdata. Use when the ctor hook missed construction (e.g. DLL loaded after campaign start).

Parameters:

  • world userdata vanilla model():world() object

Returns:

    boolean true if the pointer was captured

Usage:

    twdll.world.Capture(cm:model():world())
GetFactionCount ()
Total number of factions in the current campaign world.

Returns:

    integer or nil faction count, or nil if WORLD is not yet captured

Usage:

    local n = twdll.world.GetFactionCount()
GetMemoryAddress ()
Memory address of the WORLD singleton as a hexadecimal string.

Returns:

    string or nil memory address (e.g. "0x12345678"), or nil if not yet captured

Usage:

    local addr = twdll.world.GetMemoryAddress()
