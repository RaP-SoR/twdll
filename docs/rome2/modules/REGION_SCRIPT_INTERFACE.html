Functions

DumpInts (start_offset, count)
Diagnostic: log a run of 32-bit integers starting at start_offset. Writes one [DIAG][region] line to twdll.log. Clamps count to 1..64.

Parameters:

  • start_offset integer byte offset (should be 4-byte aligned)
  • count integer number of ints to dump

Returns:

    boolean true if the dump was written

Usage:

    region:DumpInts(0x0, 32)
GetIntAtOffset (offset)
Diagnostic: read a 32-bit signed integer at a byte offset from the region object. Temporary helper for layout discovery — not a stable gameplay API.

Parameters:

  • offset integer byte offset from the start of the region object

Returns:

    integer or nil value at the offset, or nil if the wrapper is invalid

Usage:

    local v = region:GetIntAtOffset(0x50)
GetMemoryAddress ()
Memory address of the region object in hexadecimal format.

Returns:

    string memory address (e.g. "0x12345678")

Usage:

    local addr = region:GetMemoryAddress()
SetIntAtOffset (offset, value)
Diagnostic: write a 32-bit signed integer at a byte offset on the region object. Temporary helper for layout discovery — not a stable gameplay API.

Parameters:

  • offset integer byte offset from the start of the region object
  • value integer value to write

Usage:

    region:SetIntAtOffset(0x80, 100000)
